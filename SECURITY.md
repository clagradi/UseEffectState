# Security Policy

## Supported versions

Security fixes are applied to the latest published patch line.

## Reporting a vulnerability

Please do not open a public GitHub issue for security problems.

Report vulnerabilities by email to: cgradi@icloud.com

Include:

- Affected version
- Reproduction details
- Impact assessment
- Suggested mitigation (if known)

We will acknowledge receipt, confirm triage, and provide a remediation timeline.
