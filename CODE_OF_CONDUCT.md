# Code of Conduct

This project is committed to a respectful, harassment-free environment for everyone.

## Expected behavior

- Be respectful and constructive.
- Assume good intent and discuss ideas, not people.
- Provide actionable technical feedback.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks.
- Publishing private information without consent.
- Repeated disruptive behavior after warning.

## Reporting

Report conduct issues to cgradi@icloud.com.
